# Tailwind for Waypoint

Read the current repository's styling rules and the design-system token/theme skills. Use published `@waypoint/tokens` and existing component APIs, preserve the mockup's responsive behavior and French user-facing text, and avoid inventing a second token system. Check the configured Tailwind version before using version-specific syntax. Verify affected component states, keyboard interaction, and responsive layouts with the available project checks.

Consult the official documentation for the version actually used: https://tailwindcss.com/docs.
